# CarManagerPro 🚗

**CarManagerPro** — это профессиональная ERP-система для владельцев автопарков и водителей. Приложение предназначено для комплексного учета эксплуатации транспортных средств, контроля складских запасов и детального финансового анализа.

---

## 🛠 Стек технологий (Tech Stack)

*   **Language:** [Kotlin](https://kotlinlang.org)
*   **UI:** Jetpack Compose (Modern UI Toolkit)
*   **Architecture:** MVVM + Clean Architecture
*   **Database:** Room (локальное кэширование данных)
*   **Auth & Backend:** **Firebase Authentication** (вход по Email/Google)
*   **ML Integration:** Google ML Kit (Text Recognition для одометра)
*   **Background Tasks:** WorkManager (уведомления и фоновые проверки)
*   **DI:** Hilt (Dependency Injection)
*   **Networking:** Retrofit 2 + OkHttp

---

## 📋 Функциональные модули

### 1. Аккаунт Владельца (Admin Profile)
*   **Авторизация:** Безопасный вход через Firebase. Аккаунт является «владельцем» всей структуры данных.
*   **Глобальные настройки:**
    *   Смена языков интерфейса (Localization).
    *   Выбор единиц измерения (км/мили, литры/галлоны).
    *   Настройка валюты, налоговых ставок и комиссий (ручной ввод или пресеты по странам).

### 2. Управление ресурсами
*   **Автопарк:** Детальные карточки авто (Марка, модель, цвет, VIN, мощность, тип двигателя, тип брендирования).
*   **Цифровой сейф:** Хранение и просмотр фото авто документов (СТС, ПТС, ОСАГО, КАСКО).
*   **Штат:** База водителей (ФИО, дата рождения, фото ВУ и паспорта) с функцией закрепления за автомобилем.

### 3. Эксплуатация и Smart-ввод
*   **Журнал смен:** Фиксация пробега на начало и конец дня, ввод выручки за смену.
*   **Computer Vision:** Автоматическое распознавание показаний одометра по фотографии (интеграция **ML Kit**).
*   **Топливный модуль:** Учет заправок (сеть АЗС, тип топлива, объем, итоговая стоимость).

### 4. Сервис и Склад
*   **Техническое обслуживание (ТО):** Полная история ремонтов, сервисных работ и покупки запчастей.
*   **Smart Notifications:** 
    *   Напоминания о замене расходников по пробегу.
    *   Уведомления об истечении сроков документов (страховки, права) по дате.
*   **Складской учет:** 
    *   *Общий склад:* Запчасти и расходники в наличии у владельца.
    *   *Инвентарь:* Список инструментов и вещей внутри конкретного автомобиля.

### 5. Аналитика и Интеграции
*   **Финансовый отчет:** Автоматический расчет прибыли, убытков и общего баланса средств.
*   **Эффективность:** Средний расход топлива и стоимость владения (TCO) на 1 км пробега.
*   **Dashboard:** Интеграция сторонних API для отображения погоды, дорожных пробок и цен на топливо на картах.
