В данном документе фиксируется текущее состояние разработки, принятые архитектурные решения и технический прогресс.

## 📍 Текущий статус
**Стадия:** Инициализация проекта (Этап 1 по Roadmap).
**Актуальная задача:** Проектирование схемы базы данных (Database Schema) и настройка базового стека.

## 🏗 Принятые архитектурные решения

### 1. Архитектурный паттерн: MVVM + Clean Architecture
Для обеспечения тестируемости и масштабируемости выбрано разделение на слои:
- **Data:** Реализация репозиториев, Room DB, Firebase Auth и API.
- **Domain:** Бизнес-логика (Use Cases) и модели сущностей.
- **UI:** Jetpack Compose со своими ViewModel.

### 2. Структура данных (Логическая иерархия)
Все данные в приложении имеют строгую привязку к `OwnerID` (Firebase User ID):
- `Owner` (Account) -> владеет всеми сущностями.
- `Vehicle` -> основной объект учета.
- `Driver` -> может быть назначен на конкретное `Vehicle`.

### 3. Технологический стек (уже в плане):
- **UI:** Jetpack Compose (Modern Declarative UI).
- **DI:** Hilt (для управления зависимостями).
- **Local DB:** Room (с поддержкой Flow для реактивного обновления UI).
